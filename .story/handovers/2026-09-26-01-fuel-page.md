## Before pushing — read this

`main` is deploy-on-commit. The next push runs **five migrations** on prod at startup:
- `0017`–`0019`: T-006 — add nullable columns, backfill, then SET NOT NULL. Rehearsed on a copy of the local DB with 0 differences from the old live join.
- `0020`–`0022`: fuel — additive only (carbs/fat, portion, `fuel_item` + `fuel_entry.item_id`).

`GET /api/fuel/today` is **removed** in favour of `/day/:date`. Web and API ship in one container, so nothing else calls it.

## Decisions taken (don't relitigate)

- **Nutrition scope** (owner, this session): four macros; foods from a personal food memory, **never** a food database or barcodes; Fuel is its own tab.
- **Portion is corrected after the tap, not chosen before it.** The owner picked this over long-press. The label never gains "×2"; the portion lives in its own column.
- **Only the current part of the day shows "Nothing yet"**, not every part still ahead.
- **Expenditure uses a regression slope, not an EWMA**, because the EWMA lags at the window's end. Weight is in lb, at 3500 kcal/lb, from `@afya/shared`.
- **Targets are edited only on the Week view.**
